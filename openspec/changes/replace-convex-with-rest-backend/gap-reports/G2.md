# G2 — Orden estable de Catálogo

## Operación e impacto
Navegar ventanas offset de Clase, Familia o Tipo no garantiza orden, continuidad, exhaustividad, ausencia de duplicados ni posición estable.

## Evidencia pública revisada
El contrato documenta `offset`, `limit`, `hasPrevious` y `hasNext`, pero no orden estable ni consistencia entre ventanas.

## Petición no realizada
No se enviará petición exploratoria ni se agregará orden, deduplicación o cursor sintético desde frontend.

## Decisión humana requerida
Si luego se requiere continuidad o recorrido exhaustivo, se necesita un contrato público que defina orden y consistencia.
