# Manual de Identidad Gráfica GARFEX

> Esta versión convierte a texto estructurado el contenido del manual original y describe también las reglas visuales que aparecen en sus ejemplos.
>
> **Importante:** cuando el PDF presenta inconsistencias de redacción o tipografía, se conservan y se señalan en una sección de observaciones para no inventar reglas nuevas.

## 1. Identidad de la marca

**GARFEX** es una empresa especializada en:

- Diseño eléctrico.
- Construcción eléctrica.
- Mantenimiento eléctrico.

El manual describe a GARFEX como una empresa comprometida con la calidad y con experiencia en obras e instalaciones de media tensión.

### Descriptor corporativo

**DISEÑO, CONSTRUCCIÓN Y MANTENIMIENTO ELÉCTRICO**

**¡Enciende el potencial de tu empresa!**

# 2. Estructura de identidad

La identidad gráfica se presenta principalmente en dos formatos:

## 2.1 Logotipo completo

Está compuesto por:

1. Isotipo: la letra **G** integrada con un rayo.
2. Nombre: **GARFEX**.
3. Descriptor: **DISEÑO, CONSTRUCCIÓN Y MANTENIMIENTO ELÉCTRICO**.
4. En algunas aplicaciones se muestra una línea horizontal como parte del lockup gráfico.

El logotipo completo se recomienda principalmente para documentos formales, por ejemplo:

- Facturas.
- Hojas y documentos corporativos.
- Papelería institucional.
- Comunicaciones formales.

## 2.2 Isotipo

El manual permite usar de forma independiente el símbolo formado por:

- La letra **G**.
- El rayo.

El documento indica que esta versión sintetizada puede utilizarse en:

- Artículos promocionales.
- Souvenirs.
- Uniformes.
- Algunos medios impresos.

> Nota terminológica: el PDF usa en una sección la palabra “Isótopo”; por el contexto gráfico se refiere al **isotipo**.

# 3. Normas fundamentales

El manual establece tres normas principales para garantizar un uso consistente de la marca.

## 3.1 Área de restricción / área de seguridad

Debe existir un espacio libre entre el logotipo y cualquier otro elemento que lo rodee.

La referencia visual utiliza un módulo denominado **1x** alrededor del logotipo.

### Regla para IA

- No colocar texto, imágenes, líneas, bordes u otros elementos dentro del área de seguridad.
- Mantener como mínimo el margen visual equivalente al módulo **1x** definido por el manual.

## 3.2 Proporción

El manual muestra una proporción aproximada del logotipo completo de:

- **Ancho: 5x**
- **Alto: 1x**

### Regla para IA

- Mantener siempre la relación de aspecto original.
- No estirar horizontalmente.
- No comprimir horizontalmente.
- No estirar verticalmente.
- No deformar el isotipo, la palabra GARFEX ni el descriptor.

## 3.3 Tamaño mínimo

El manual diferencia entre aplicación impresa y bordado.

| Aplicación | Tamaño mínimo mostrado |
|---|---:|
| Impreso | 1 cm |
| Bordado | 3 cm |

### Regla para IA

No reducir el logotipo por debajo del tamaño mínimo correspondiente si ello compromete la legibilidad.

# 4. Aplicaciones permitidas del logotipo completo

El manual muestra cinco variantes principales.

## 4.1 Logotipo a color / positivo

- Fondo: claro o blanco.
- GARFEX y elementos principales: rojo corporativo.
- **Rayo: amarillo corporativo.**
- Fondo del archivo: preferiblemente transparente.

## 4.2 Logotipo 1 tinta / positivo

- Elementos principales: rojo corporativo.
- **Rayo: amarillo corporativo.**
- Fondo: claro o transparente.

> Aunque el título del manual dice “1 tinta”, el ejemplo visual conserva el rayo amarillo.

## 4.3 Logotipo 1 tinta / negativo

- Elementos principales: blancos.
- **Rayo: amarillo corporativo.**
- Se muestra aplicado sobre fondo rojo corporativo.
- El fondo rojo es una **muestra de aplicación**, no necesariamente parte obligatoria del archivo del logotipo.

## 4.4 Positivo negro

- Elementos principales: negros.
- **Rayo: amarillo corporativo.**
- Fondo: claro o transparente.

## 4.5 Negativo blanco

- Elementos principales: blancos.
- **Rayo: amarillo corporativo.**
- Se muestra sobre fondo negro para asegurar contraste.
- El archivo maestro puede mantenerse con fondo transparente.

### Regla visual importante

**En los ejemplos permitidos del manual, el rayo permanece amarillo en todas las variantes.**

# 9. Usos incorrectos

El manual prohíbe o desaconseja los siguientes usos:

## 9.1 Efectos de sombreado

No agregar:

- Drop shadows.
- Sombras.
- Resplandores.
- Efectos que disminuyan la claridad.

## 9.2 Fondos del mismo color

No colocar el logotipo sobre un fondo que reduzca el contraste y haga que sus elementos desaparezcan.

### Regla para IA

Seleccionar la versión positiva o negativa que asegure contraste suficiente.

## 9.3 Distorsionar

No alterar la proporción original.

Prohibido:

- Estirar.
- Aplastar.
- Comprimir.
- Deformar.
- Cambiar proporciones internas.

## 9.4 Cambiar color

No cambiar los colores oficiales por otros colores arbitrarios.

El ejemplo incorrecto muestra una versión en colores ajenos a la identidad.

## 9.5 Girar

No rotar o inclinar el logotipo de manera arbitraria.

### Resumen de prohibiciones

```text
NO shadow
NO glow
NO stretch
NO squash
NO arbitrary recolor
NO rotation
NO low-contrast background
NO modification of proportions
```

# 10. Sistema de Diseño Digital GARFEX

> Esta sección amplía el manual de identidad para aplicaciones web, móviles, dashboards y software de uso prolongado.
>
> **Objetivo:** mantener la identidad GARFEX con una interfaz técnica, limpia, profesional, moderna y de baja fatiga visual.
>
> Los colores del logotipo **no cambian**. La paleta digital crea colores funcionales y superficies alrededor de la marca.

## 10.1 Principios UX/UI

La interfaz digital GARFEX debe seguir estos principios:

- Las superficies grandes deben usar tonos neutros y suaves.
- El rojo y amarillo corporativos deben funcionar principalmente como acentos.
- Evitar grandes áreas saturadas en rojo o amarillo durante uso prolongado.
- El amarillo GARFEX no debe utilizarse para párrafos o texto pequeño sobre fondos claros.
- El color no debe ser el único indicador de estado.
- Debe existir contraste suficiente para texto, iconos y controles.
- Light y Dark deben diseñarse como dos temas completos, no como una simple inversión de colores.
- En modo oscuro se prefieren grises profundos en lugar de negro puro como fondo principal.
- Los estados semánticos deben diferenciarse de los colores de marca.

## 10.2 Colores de marca digitales

Estos valores permanecen como referencia oficial del logotipo y elementos de identidad:

| Token | HEX | Uso |
|---|---:|---|
| `brand.red` | `#7C0000` | Rojo corporativo GARFEX |
| `brand.yellow` | `#F2D031` | Rayo y acento corporativo |
| `brand.black` | `#000000` | Negro |
| `brand.white` | `#FFFFFF` | Blanco |

> **Regla:** el logotipo conserva siempre sus colores definidos. Los colores funcionales de UI pueden usar variaciones de luminosidad o saturación para asegurar contraste y comodidad visual.

# 11. Tema claro — GARFEX Soft Light

El tema claro utiliza neutros ligeramente cálidos para evitar una interfaz excesivamente blanca y reducir la fatiga visual.

| Token | HEX | Uso recomendado |
|---|---:|---|
| `background` | `#F7F6F3` | Fondo principal de la aplicación |
| `surface` | `#FFFFFF` | Cards, paneles y contenedores |
| `surface-subtle` | `#F1F0EC` | Secciones secundarias |
| `surface-elevated` | `#FFFFFF` | Menús, dialogs y overlays |
| `text-primary` | `#1F1F1D` | Texto principal |
| `text-secondary` | `#5F5D58` | Texto secundario |
| `text-muted` | `#6D6A64` | Ayuda, metadata, labels secundarios |
| `border` | `#D9D6CF` | Bordes suaves |
| `border-strong` | `#B8B4AB` | Separadores importantes |
| `primary` | `#7C0000` | Acción principal |
| `primary-hover` | `#680000` | Hover |
| `primary-active` | `#540000` | Pressed / active |
| `primary-subtle` | `#F7EAEA` | Selecciones y fondos de énfasis suave |
| `accent` | `#F2D031` | Acento GARFEX |
| `on-accent` | `#2B2500` | Texto/icono sobre amarillo |
| `focus` | `#8A6800` | Focus ring |

### 11.1 Reglas de uso del tema claro

- El fondo principal no debe ser rojo ni amarillo.
- Usar `surface` para cards sobre `background`.
- Reservar el rojo GARFEX para CTA principales, navegación activa y énfasis.
- Usar amarillo en pequeños acentos, estados visuales o highlights.
- No usar `#000000` como texto general si `text-primary` ofrece suficiente contraste.
- Evitar bordes fuertes en todas las cards; priorizar separación mediante superficies y espaciado.

---

# 12. Tema oscuro — GARFEX Soft Dark

El tema oscuro utiliza grises profundos y superficies escalonadas para evitar el contraste extremo de negro puro contra blanco puro.

| Token | HEX | Uso recomendado |
|---|---:|---|
| `background` | `#161616` | Fondo principal |
| `surface` | `#1D1D1B` | Cards y paneles |
| `surface-subtle` | `#242421` | Secciones secundarias |
| `surface-elevated` | `#2B2A27` | Dialogs, menús, popovers |
| `text-primary` | `#ECEAE5` | Texto principal |
| `text-secondary` | `#C3C0B8` | Texto secundario |
| `text-muted` | `#9A978F` | Metadata y labels |
| `border` | `#383733` | Bordes suaves |
| `border-strong` | `#55534D` | Separadores importantes |
| `primary` | `#B33A3A` | Acción principal en dark mode |
| `primary-hover` | `#C14747` | Hover |
| `primary-active` | `#982E2E` | Pressed / active |
| `primary-subtle` | `#351D1D` | Selección o fondo tenue |
| `accent` | `#F2D031` | Acento GARFEX |
| `on-accent` | `#2B2500` | Texto/icono sobre amarillo |
| `focus` | `#E4B84A` | Focus ring |

### 12.1 Regla especial del rojo en modo oscuro

El logotipo GARFEX conserva el rojo oficial `#7C0000`.

Los controles interactivos pueden utilizar `#B33A3A` en modo oscuro para obtener mejor visibilidad y contraste sobre fondos profundos.

Esto **no modifica la identidad del logotipo**; es una adaptación funcional exclusiva de UI.

### 12.2 Reglas de uso del tema oscuro

- Evitar `#000000` como fondo dominante.
- No usar blanco puro para todos los textos.
- Usar diferencias de superficie para crear jerarquía.
- Mantener el amarillo como acento puntual.
- Evitar grandes bloques de rojo saturado.
- No iluminar todos los elementos simultáneamente.
- El contenido importante debe destacar por jerarquía, no únicamente por saturación.

# 13. Colores semánticos

Los estados funcionales deben ser independientes de los colores de marca.

| Estado | Light | Dark | Uso |
|---|---:|---:|---|
| Success | `#2F6B4F` | `#6FCF97` | Éxito, completado, correcto |
| Warning | `#8A6800` | `#E4B84A` | Advertencia |
| Error | `#B4232F` | `#FF8A94` | Error, fallo, acción destructiva |
| Info | `#356A8A` | `#76B6D6` | Información |

### 13.1 Reglas semánticas

- No usar el rojo corporativo GARFEX como único color de error.
- Acompañar estados con icono, texto o cambio de forma cuando sea necesario.
- Mantener consistencia entre Light y Dark.
- No crear estados nuevos con colores arbitrarios.

# 15. Reglas de accesibilidad y confort visual

Para productos digitales GARFEX:

- Texto normal debe buscar un contraste mínimo equivalente a WCAG AA.
- Texto grande y controles deben mantener contraste suficiente frente a su fondo.
- No usar el amarillo corporativo para texto pequeño sobre blanco.
- No depender únicamente del color para comunicar error, éxito o selección.
- Focus debe ser claramente visible.
- Los estados `hover`, `pressed`, `selected`, `disabled` y `focus` deben ser distinguibles.
- Evitar animaciones luminosas o cambios de color muy intensos.
- Preferir fondos suaves y jerarquía por espaciado/superficie antes que saturación.
- El usuario debe poder elegir entre:
  - `Light`
  - `Dark`
  - `System`

# 19. Reglas operativas para agentes de IA

Esta sección resume el manual en instrucciones directas para sistemas generativos.

1. Usar únicamente los colores corporativos definidos.

3. Respetar el área de seguridad.

9. No recolorear el logo con colores no autorizados.
10. No rotarlo.
11. No deformarlo.
12. Usar Nexa para titulares cuando esté disponible.
13. Usar RNS Sanz para texto amplio.
14. Usar Monola Script únicamente como fuente de apoyo decorativa cuando proceda.
15. Mantener una apariencia limpia, técnica, profesional e institucional.

# 21. Inconsistencias y puntos que requieren validación humana

Para evitar que una IA convierta posibles errores del PDF en reglas definitivas, deben considerarse estos puntos:

## 13.1 “1 tinta” con rayo amarillo

Los ejemplos denominados **“1 tinta”** visualmente mantienen el rayo amarillo.

Por lo tanto, para esta versión Markdown se interpreta la muestra visual como regla:

> **El rayo amarillo se conserva en todas las variantes permitidas.**

Esto coincide con las aplicaciones visuales mostradas tanto para el logotipo completo como para el isotipo.

## 13.2 Amarillo del PDF vs. amarillo del logotipo vectorial

El PDF del manual especifica el amarillo como `#F4CF00` (Pantone 109 C).

Sin embargo, el archivo vectorial original del logotipo suministrado utiliza `#F2D031`.

Para esta versión operativa destinada a IA se adopta como valor canónico:

```text
GARFEX_YELLOW = #F2D031
```

porque el usuario solicitó que el manual quede alineado con el color real del logotipo.

El rojo sí coincide con el manual y se mantiene en:

```text
GARFEX_RED = #7C0000
```

## 13.3 Monotype Corsiva vs. Monola Script

Una página de “Aplicación de estilo” menciona:

- Titulares: Monotype Corsiva.

Pero las páginas tipográficas principales indican:

- Nexa como fuente corporativa para titulares.
- Monola Script como fuente secundaria/de apoyo.

**No se debe asumir que Monotype Corsiva reemplaza a Nexa o Monola Script sin validación adicional.**

## 13.4 RNS Sanz

El manual escribe la familia como **RNS Sanz**. Se mantiene esta grafía tal como aparece en el documento.

## 13.5 Fondos rojo y negro de las versiones negativas

Los rectángulos rojo y negro mostrados en las láminas son ejemplos de aplicación y contraste.

Para archivos maestros:

- SVG: fondo transparente.
- PNG: fondo transparente.
- El fondo debe añadirse en la pieza donde se aplique el logo, no formar parte obligatoria del logo.

# 22. Prioridad de reglas para una IA

Si una IA recibe instrucciones para crear una pieza GARFEX, debe aplicar las reglas en este orden:

1. **Integridad del logotipo.**
2. **Colores corporativos.**
3. **Rayo amarillo.**
4. **Proporción y área de seguridad.**
5. **Contraste positivo/negativo.**
6. **Tipografía corporativa.**
7. **Composición gráfica.**
8. **Estilo de la pieza.**

Nunca se debe sacrificar una regla de identidad para obtener un diseño más llamativo.
